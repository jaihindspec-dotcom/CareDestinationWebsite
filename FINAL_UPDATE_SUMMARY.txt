🔧 HOW TO USE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Open the Website
────────────────────────────────────────────────────────────────────────
• Double-click: index.html
• OR use any web browser

STEP 2: Try the Search
────────────────────────────────────────────────────────────────────────
1. Look at top right corner
2. Click the magnifying glass icon (🔍)
3. Choose a tab: Treatments | Hospitals | Doctors
4. Start typing anything
5. See instant results!
6. Click any result to navigate

Example Searches:
• "heart" → Shows cardiac treatments
• "Apollo" → Shows Apollo Hospital
• "cardiology" → Shows cardiologists

STEP 3: Try Translation
────────────────────────────────────────────────────────────────────────
1. Look at top right corner (next to search)
2. Click the language dropdown
3. Select any language (e.g., हिन्दी, 中文, Español)
4. Wait 2-3 seconds
5. Entire website translates!
6. Switch back to English anytime
