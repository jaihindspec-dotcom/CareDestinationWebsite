## Troubleshooting

### If dropdown doesn't appear:
1. Clear browser cache (Ctrl+Shift+R or Cmd+Shift+R)
2. Make sure JavaScript is enabled
3. Check if you have internet connection (Google Translate needs it)

### If translation doesn't work:
1. Wait 3-5 seconds after selecting language
2. Refresh the page and try again
3. Check browser console for errors (F12)
4. Make sure Google Translate isn't blocked by firewall/ad blocker

### If dropdown looks different:
1. The custom styling should match your website
2. If it looks like default browser style, check if CSS loaded
3. Clear cache and reload
